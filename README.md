# 📚 DSA Solutions

Daily Data Structures and Algorithms practice in C++, with problem links, explanations, and time/space complexity.

This repository is organized by topic (arrays, linked list, binary search, etc.) and contains clean, well-structured solutions for LeetCode and GeeksforGeeks problems.

---

## 🧩 Structure

dsa-solutions/
├─ arrays/
├─ linked_list/
└─ ...

Each folder contains `.cpp` files for DSA problems with:

- Problem name  
- Problem link  
- Approach  
- Time complexity  
- Space complexity  
- Explanation (in comments)
